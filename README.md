# learnCKB

A multi-campaign workspace for hands-on Build on CKB tutorials, contracts,
dApps, and verifiable OffCKB devnet proof.

## Campaigns

| Campaign | Build | Package |
| --- | --- | --- |
| [#01](campaign-01/README.md) | Capacity-guard lock with CKB JavaScript VM | [Implementation and proof](campaign-01/README.md) |
| [#02](campaign-02-proof/README.md) | Store Data on Cell | [Tutorial proof](campaign-02-proof/README.md) |
| [#03](campaign-03/README.md) | Simple hash lock and transfer/unlock frontend | [Implementation and proof](campaign-03/README.md) |
| [#04](challenge-4/README.md) | Create a Digital Object (DOB) with Spore SDK | [Implementation and proof](challenge-4/README.md) |

## Proof Model

Campaigns run on private OffCKB local devnets unless their package says
otherwise. Local-chain results are documented with source, deployment
artifacts, RPC evidence, logs, screenshots, and offline verification where
appropriate. These transactions are not expected to appear on public CKB
explorers.

## Reflections

Campaign reflections are intentionally not generated in this repository. The
participant writes each final reflection from their own experience.
